# Python-exercise-12-


This program solves the problem of categorizing a set of numbers by identifying how many are positive, negative, or zero. It takes a sequence of space-separated inputs, converts them into a list of integers, and iterates through that list to increment counters for each classification.
To run it, simply paste the code into any Python compiler or IDE and execute it; the program will prompt you to input your numbers separated by spaces. The logic was implemented using basic Python programming constructs: input() for data acquisition, split() for parsing, a for loop for iteration, and standard conditional if-elif-else statements for categorization.
